# Min hemmsidan

En enkel hemsidan som presentera vem jag är och min intress och hur man kan ta kontakt med mig

Denna hemsida skapades av html och litten css som border för tabellen och width för att justera bilder.

## Frågor som ska svaras

### Vad är skillnaden mellan git add och git commit?

1. Git add användas för att lägga in ändrade filler i staging area och git commit gör man så att man spara en version av projeckt som sedan kan kommer till baka åt.

### Varför använder man branches istället för att jobba direkt i main?

2. För att man vill inte de pulicerade sidan ska hålla på ändras verje gån när man har ändrat på ett små saker t.ex en stavfel.

### Vad händer rent praktiskt när man gör en merge?

3. Det som händer med merge är att man kopera den ändrade verion och lägger till den inom det gammla version.

### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?

4. Skillnad mellan de är att man push i GitHub kommer det inte skapa ett webbsidan direkt.

### Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?

5. För att exkludera en fill i verisionshantering använder man git kommando gitignore.
